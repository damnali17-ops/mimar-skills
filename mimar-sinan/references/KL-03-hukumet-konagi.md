# KL-03 — Hükümet Konağı / Valilik / Kaymakamlık Kontrol Listesi (İçişleri Esasları)

## A · Makam ve yönetici odaları (§A, net m²)
- [ ] Vali 80 · Vali Yrd 40 · İl Müd 35 · Kaymakam 60 · İlçe Müd 24 — **her biri ±%5**
- [ ] Makam ekleri: özel kalem · sekreter · bekleme · makam toplantı · dinlenme + WC/duş · koruma (tipik 🟡)
- [ ] Makam odası dış cephede; bekleme → sekreter → makam sıralaması
- [ ] Şeref salonu / protokol (il 60–100, ilçe 30–50 🔴)
- [ ] Lojman HK içinde **yok**

## B · Bina kriterleri (§B — UD-B)
- [ ] **Kat yüksekliği ≥4.50 m** (tüm katlar; kesit yazılı)
- [ ] **Kat sayısı ≤ zemin + 2** (bodrum hariç) — plan Hmax daha düşükse plan
- [ ] **Makam katı zemin+2 içinde**
- [ ] Giriş holü 8 m (çift kat yüksekliğinde galeri) — ölçünün yükseklik/genişlik olduğu esas metinden teyit 🟡
- [ ] Vatandaş yoğun birimler zemin katta, giriş holünden doğrudan
- [ ] Ana giriş + protokol girişi + servis/personel girişi ayrı
- [ ] Ana giriş erişilebilir ve güvenlikli (TS 9111 §4.5.4 tahsisli giriş)
- [ ] Protokol asansörü / makam katı erişimi (varsa) + genel asansör (≥4 kat tesis; HK genelde 3 kat → yer; **sedye + erişilebilirlik için tesis önerilir** 🟡)
- [ ] Bodrum: sığınak (emsal ≥1 500) · arşiv · teknik · makam kapalı otoparkı 🔴

## C · Vaziyet ve dış mekân
- [ ] Tören alanı giriş aksında, ölçü sınıfa göre 🔴
- [ ] Bayrak direği, Atatürk büstü/anıtı konumu
- [ ] Makam araç otoparkı (kapalı/örtülü) + genel otopark + engelli (1/20, girişe ≤30 m)
- [ ] Protokol araç yanaşma alanı, servis yolu
- [ ] Çekme mesafeleri ve emsal (KL-01 A)

## D · Cephe, malzeme, kimlik
- [ ] Kalıcı doğal malzeme (taş kaplama vb.), kamu kimliği; malzeme listesi esas metinden 🔴
- [ ] Eğimli/kırma çatı, yerel iklim uyumu 🟡
- [ ] Mimari estetik komisyonu kararı ile uyum

## E · İç düzen
- [ ] Vatandaş bekleme 3 m²/kişi anlık; danışma bankosu erişilebilir (≤86 / ≥75 / 150×150)
- [ ] Toplantı salonu paylaşımlı; konferans/nikâh salonu ayrı giriş + kaçış
- [ ] Şeref salonu makam katına yakın
- [ ] KBS §4.3–4.8 normları çalışan/ortak alanlarda (KL-01 I)
- [ ] Sirkülasyon %60 (geniş hol/galeri HK'da oranı yükseltir → U-N ile not)

## F · Teslim (§C avan · §D uygulama)
- [ ] Avan: vaziyet (tören, bayrak, otopark, girişler) · kat planları + m² cetveli · ≥2 kesit (giriş holünden biri) · cepheler · ihtiyaç programı karşılaştırma · imar durumu · zemin etüdü ön raporu
- [ ] Uygulama: mahal listesi · kapı-pencere cetveli · merdiven / erişilebilir WC / rampa detayı 1/20 · tahliye projesi + yağmurlama · iç malzeme listesi
- [ ] Onay zinciri: İçişleri (İller İdaresi) + ÇŞİDB — sözleşmeye göre 🟡
